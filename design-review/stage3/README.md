# Этап 3 — макеты направлений

Все рендеры — 2880×1800 (окно 1440×900, DPR 2), тот же масштаб, что у скриншотов этапа 0.
Данные синтетические: те же 28 писем, что в `stage0/` (`mocks/data.js`).

- `mocks/` — исходники: `mock.html`, `mock.css`, `data.js`, `render.js`. Экран выбирается хэшем,
  например `mock.html#d1-inbox`. Можно открыть в браузере как обычный файл.
- `renders/` — готовые экраны: `mock-<направление>-<экран>.png`.
  Направления: `d1` секции решений, `d2` проход по решениям, `d3` тихий инбокс, `sh` общие экраны.
  Экраны: `inbox`, `thread`, `agent`, `confirm`, `empty`, `loading`, `error`.
- `compare/` — пары «было → стало» (слева скриншот этапа 0, справа макет).
- `tools/render-all.sh`, `tools/compare-all.sh` — перерисовать всё (Electron из `node_modules`, без сети).
